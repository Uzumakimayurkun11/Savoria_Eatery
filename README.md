# Savora — Food Ordering App Concept

Savora is a food ordering app concept designed to make every step feel simple and welcoming: discover a restaurant, customise a meal, place an order, and follow it to your door.

**[Open the live preview](https://uzumakimayurkun11.github.io/Savoria_Eatery/)** · **[Browse all 26 screens](#screens)**

## About the project

This project presents a complete mobile app journey in 26 screens. The visual direction pairs warm cream backgrounds and rounded cards with Savora orange actions, dark readable type, and fresh green delivery states.

The screens were designed in Figma and exported as PNGs. The live preview brings them together in a responsive phone mockup, so you can browse the experience without downloading the images.

## Explore the preview

The preview page includes:

- A phone-sized view of each screen
- Filters for onboarding, discovery, checkout and delivery, and after delivery
- Clickable screen thumbnails and previous/next controls
- Keyboard navigation with the left and right arrow keys

This is a visual design prototype. Restaurant search, ordering, payment, and delivery tracking are not connected to live services.

## Screens

The app journey covers:

1. **Getting started:** splash, onboarding, sign in, verification, delivery address, and profile setup
2. **Discovering food:** home, search, filters, cuisines, offers, map, collections, and restaurant menu
3. **Ordering:** item customisation, cart, delivery details, address selection, payment, and order review
4. **After checkout:** order confirmation, live tracking, delivery confirmation, rating, and order history
