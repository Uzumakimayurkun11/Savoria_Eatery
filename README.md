# Savora — food ordering app concept

Savora is a 26-screen food ordering app concept designed around warm cream surfaces, fresh orange accents, and a simple journey from discovery through delivery.

## Live preview

The preview is a lightweight static site. It presents the exported screens in a phone mockup, with clickable screen thumbnails, journey filters, and previous/next controls. It uses the PNG exports in this repository; it does not connect to restaurant, payment, or delivery services.

To publish it with GitHub Pages:

1. Open the repository's **Settings** on GitHub.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then click **Save**.
5. After GitHub finishes publishing, open the Pages URL shown on that settings page.

## Screens

The design moves through onboarding, restaurant discovery, checkout, delivery tracking, ratings, and order history. Open `index.html` locally or through GitHub Pages to browse all 26 screens.

## Design source

The screens were designed in Figma and exported as PNG images for this repository.
